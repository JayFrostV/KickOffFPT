II. Software Requirement Specification
1. Overall Requirements
1.1 Context Diagram
Quiz Application is a system that allows users to discover, create, manage, and participate in quizzes.
Users can create their own quizzes and questions, maintain a personal question bank, reuse public
questions, and publish quizzes for other users to access.
The system supports three main actors: Guest, User, and Administrator. Guests can browse public
quizzes and try a limited number of trial quizzes. Registered users can participate in quizzes, create
and manage their own quizzes and question banks. Administrators are responsible for managing users,
quizzes, questions, and inappropriate content within the system.
QuizApplication- SRS Document Page 4/18
=== Page 5/22 ===
1.2 Main Business Processes
The Quiz Application supports the main business processes of participating in quizzes, creating and
publishing quizzes, and administering system content. Guests have limited access to trial quizzes,
while registered users can fully participate in quizzes and create their own quiz content.
1.2.1 Quiz Participation Process
This process describes how a Guest or User searches for and participates in a public quiz. Guests
can only access a limited number of trial quizzes. When the trial limit is reached, the Guest must
register or log in to continue. Registered Users can participate in available public quizzes and view
their results after submission.
1.2.2 Quiz Creation and Publishing Process
This process allows a registered User to create and manage a quiz. Questions can be created manually
or selected from the Question Bank. After completing the quiz, the User can save it as private or
publish it for other users.

1.2.3. Content Administration Process
This process describes how an Administrator monitors and manages users and public content. The
Administrator can review quizzes or questions and take appropriate action when inappropriate
content is identified.

1.4 Entity Relationship Diagram
The Entity Relationship Diagram describes the main data entities and their relationships within the
Quiz Application. In addition to quizzes, questions, and answers, the system provides Question Banks
that allow users to organize, store, and reuse questions when creating quizzes.
Questions stored in a Question Bank can be reused across multiple quizzes. The system also maintains
quiz attempts and submitted answers to support quiz participation and result evaluation.

and informs the Guest to use another email/username.

and does not create the account.

2.2.3 Submit Quiz
Item Description
Use Case ID UC09
Use Case Name Submit Quiz
Primary Actor User
Secondary Actor None
Description As a User, I want to submit my quiz answers so that the system can
evaluate my attempt and provide a result.
Preconditions The User has an active Quiz Attempt and has started the selected Quiz.
Postconditions The Quiz Attempt is marked as submitted. The submitted answers and
calculated result are stored by the system.
Normal Sequence / 1. User selects Submit Quiz.

3. System validates the submitted data.
4. System compares the submitted answers with the correct answers where

5. System calculates the quiz result.
6. System stores the submitted answers and result.
7. System marks the Quiz Attempt as completed.
8. System displays the result to the User.

Sequences / Flows final submission and allow the User to return to the quiz.

an appropriate error message.

submitted answer and marks the relevant question as pending evaluation
rather than assigning an immediate final score.

Item Description
Use Case ID UC11
Use Case Name Create Quiz
Primary Actor User
Secondary Actor None
Description As a User, I want to create a quiz so that I can organize questions and
make the quiz available for my own use or for other users.
Preconditions The User is authenticated and has permission to create quizzes.

8. System creates the Quiz and associates it with the User.
9. System confirms that the Quiz has been created successfully.

Sequences / Flows messages and does not create the Quiz until the required information is
provided.
A2 – Invalid quiz information: System displays an appropriate error
message and allows the User to correct the data.
A3 – User cancels creation: System cancels the operation and no Quiz is
created.
